### 🚀 Featured Projects

#### 🏢 [Urban Resolve](https://urban-resolve.vercel.app/)
*A full-stack, responsive citizen grievance redressal system helping communities communicate directly with municipal departments.*
* **Features:** Multi-category complaint filing, geo-tagging maps, customized officer resolution panels, and real-time community statistics.
* **Stack:** React, Vite, TailwindCSS, Vercel.
* **Code:** [GitHub Repository](https://github.com/Abhayajj/Wonderful)

#### 🏡 [WonderFull](https://wonderful-hotel.onrender.com/)
*A modern accommodation discovery and hosting marketplace allowing users to explore or host unique stays.*
* **Features:** Structured categories (Beach, Mountain, Countryside, Treehouse), interactive Leaflet map integration, price sliders, and host dashboards.
* **Stack:** Node.js, Express.js, MongoDB, EJS, Bootstrap, Render.
* **Code:** [GitHub Repository](https://github.com/Abhayajj/wonderful-hotel)

#### 🔑 [Animated Login System](https://github.com/Abhayajj/Animated-loginPage)
*A sleek and modern user login layout featuring fluid transitions and interactive micro-animations.*
* **Features:** Responsive design, clean form validation layouts, and custom keyframe animations.
* **Stack:** HTML5, CSS3.
